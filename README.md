### 📌 Projects

#### [NORI](https://github.com/HA-MYUN-HAM/HMH-SERVER) — 내부 행사 관리 플랫폼
단체 내부 행사를 생성·신청·관리할 수 있는 웹 플랫폼. Django 백엔드 설계, AWS EC2 + Nginx + uWSGI 배포, JWT·카카오 로그인, OpenAI API 연동(행사 홍보 이미지 자동 생성)을 담당했습니다.
`Django` `MySQL(RDS)` `AWS EC2` `Nginx/uWSGI` `JWT` `OpenAI API`

#### [WeWha](https://github.com/ECC-WeWha/BackEnd) — 이대생을 위한 외국인 유학생 커뮤니티
교내 유학생과 재학생이 국적별 게시판·언어교류 친구찾기로 소통하는 커뮤니티 서비스. 게시판(다목적/국적별) 도메인 전체를 설계·구현했습니다.
`Spring Boot` `Spring Security` `JWT` `MySQL`

#### [WALK GUARDIANS](https://github.com/hayeong0206/DE_project2) — 보행 약자를 위한 인도 위험도 예측 서비스
인도·도로 사진을 분석해 시각장애인·휠체어/고령자 기준 위험도를 예측하는 접근성(accessibility) 서비스. 팀 프로젝트에서 프론트엔드 전반과 백엔드 연동 서버를 담당했습니다.
`React` `FastAPI` `Canvas API`

#### [ComOn](https://github.com/EWHA-COM-ON/COM_ON_Backend) — 학생회 서비스 백엔드 (첫 백엔드 프로젝트)
학생회 소개·공약·조직도, 로그인/회원가입 기능을 가진 학생회 웹 서비스. Spring MVC + JSP + JDBC로 만든 첫 백엔드 프로젝트입니다.
`Spring MVC` `JSP` `JDBC`
